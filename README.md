#  Diwali Mini Sales Report

A small and simple **Python data analysis project** that analyzes Diwali sales data using Pandas and Matplotlib.

##  Project Goal
To answer 3 simple questions:
1. Who buys more: male or female customers?
2. Which Top 5 states generated the highest sales?
3. Which Top 5 product categories sell the most?

##  Tools Used
- Python
- Pandas
- Matplotlib

##  Files
- `Diwali Mini Sales Report.py` : main code
- `Diwali Sales Data.csv` : dataset

##  How to Run
1. Download or clone the repository
2. Install the required libraries:
   ```
   pip install pandas matplotlib
   ```
3. Update the CSV file path in the code to match your system
4. Run the script:
   ```
   python "Diwali Mini Sales Report.py"
   ```

##  Project Flow
**Load → Clean → Total → Group → Chart**

##  Key Insights
- Total Sales: ₹10.62 crore
- Total Orders: 27,981
- Female customers spent more than male customers
- Top States: Uttar Pradesh, followed by Maharashtra and Karnataka
- Top Categories: Food, followed by Clothing and Electronics
